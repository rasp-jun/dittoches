# 공격력·주문력·스킬 계수와 사거리 (2026-09-17)

디지몬 30종과 크립 4종의 전투 정의입니다. 분류, 계수, 기본 공격 방식, 사거리는 이 게임을 위한 설계이며 원작 공식 전투 수치가 아닙니다. [TFT 역할 개편](https://teamfighttactics.leagueoflegends.com/en-us/news/game-updates/roles-revamped-and-item-changes/)의 공격/마법/혼합 분류와 [TFT 계수 표기 예시](https://teamfighttactics.leagueoflegends.com/en-gb/news/game-updates/teamfight-tactics-patch-14-18-notes/)를 참고했습니다.

## 배치와 대상 선택

- 준비 중 유닛을 선택하고 아군 전장·대기석의 목적지를 가리키면 시너지의 현재/이동 후 인원과 단계 변화를 표시합니다. 교환으로 전장을 떠나는 유닛까지 반영하고, 같은 종류는 하나로 계산합니다. 배치 인원이 가득 찬 상태에서 빈 전장 칸으로 이동하려 하면 제한을 안내합니다. 실제 이동 명령 전에는 능력치가 바뀌지 않습니다.
- 기본 공격 범위는 솔로·온라인 모두 육각 거리로 계산합니다. 선택한 유닛의 범위를 하늘색 칸으로 표시하며, 준비 중 유효한 목적지를 가리키면 해당 위치의 범위를 미리 봅니다. 전투 중 선택한 유닛은 현재 위치에서 범위를 표시합니다. 스킬 자체의 범위와는 별개입니다.
- 현재 대상이 살아 있고 기본 공격 사거리 안이면 계속 공격합니다. 범위 밖의 대상을 추격하는 도중 다른 적이 사거리 안에 들어오면 가장 가까운 공격 가능 대상으로 전환합니다. 아무도 범위 안에 없다면 기존 추격을 유지해 이동 방향이 흔들리지 않게 합니다.
- 처음 대상을 고르거나 기존 대상이 죽으면 가장 가까운 적을 선택합니다. 동률은 솔로의 전투 등록 순서, 온라인의 유닛 키 순서로 결정합니다. 마법사도 기본 공격 대상을 고를 때 체력이 적은 먼 적을 우선 추격하지 않습니다.
- 스킬 준비 중 대상이 죽으면 같은 거리 기준으로 다시 고릅니다. 이미 발사된 기술은 새로운 대상으로 바꾸지 않습니다.

## 상점에서 스킬 확인

솔로·온라인 모집 카드에 공격/마법/혼합 유형과 기본 공격 사거리, 스킬 아이콘을 표시합니다. 아이콘 우클릭은 구매와 별개이며 골드가 부족해도 사용할 수 있습니다. 상점 상세의 수치는 **1성 기본 공격력·주문력 기준, 장비·시너지 미포함**입니다. 구매 후 합성이나 장비·전장 시너지로 실제 피해가 달라질 수 있습니다. 이미 보유한 유닛의 현재 수치는 해당 유닛의 정보창에서 확인합니다.

## 장비 변경 미리보기

장비 선택 후 아군에게 마우스를 올리면 오른쪽에 장착 전후 능력치를 비교합니다. 재료는 자동 합성으로 대체될 장비를, 추출기는 장비 전부를 회수한 능력치를 계산합니다. 슬롯이 가득 차고 합성도 불가능하면 거절 사유를 표시합니다. 미리보기를 보는 것만으로 장비나 보관함은 바뀌지 않습니다.

공격력·주문력·체력·방어력·마법 저항·공속·시작 마나와 해당 성급의 스킬 총 피해를 표시합니다. 전장 시너지는 전장 유닛에만 포함하고 대기석에는 장비만 적용합니다. 피해는 **대상 1명에게 모든 타격이 적중하는 경우의 방어 적용 전 합계**이며, 조건부 추가 피해·흡혈·보호막 등은 장비 설명으로 구분합니다. 전투 중 전장 장비 변경은 계속 금지합니다.

## 전투 기록의 집계 기준

| 탭 | 집계하는 값 | 구분 표시 |
|---|---|---|
| 피해 | 방어·보호막 적용 후 실제로 감소시킨 적 체력 | 기본 공격 / 스킬 |
| 받음 | 실제 체력 감소 + 자신의 보호막이 흡수한 피해 | 체력 감소 / 보호막 흡수 |
| 회복 | 실제로 회복시킨 체력. 흡혈·재생 포함 | 초과 회복 제외 |
| 보호 | 상한에 막히지 않고 실제로 생성한 보호막 | 실제 흡수량은 ‘받음’ 탭에서 확인 |

이미 죽은 대상과 남은 체력을 넘기는 피해는 추가 피해 점수로 계산하지 않습니다. 물리/마법 유형과 기본 공격/스킬 분류는 별개입니다. 물리 스킬도 스킬 피해로 집계합니다. 시전 횟수는 시전 시작 횟수이며 도중에 취소된 시전도 포함합니다.

온라인 집계는 서버가 계산하며 화면은 현재 재생 프레임까지만 보여줍니다. 마지막 프레임의 기록은 라운드 정산 때 저장해 준비 단계·경기 결과·재접속 후 제공하며, 장비 보관함이나 대기석 정보를 포함하지 않습니다. 방이 종료 후 정리되거나 서버를 재시작하면 기록도 사라집니다. 솔로 기록도 이번 실행의 최근 전투 한 회만 보관합니다.

## 능력치 공식

- 공격력 = 기본 공격력 × `1.5^(성급−1)` × `(1 + 장비·시너지 공격력 증가율 합계)`.
- 주문력 = **100 + 장비·시너지 주문력 합계**. 별을 올려도 기본 주문력 100은 같고 스킬의 성급별 계수가 증가합니다.
- 스킬 총 피해 = **현재 공격력 × 공격 계수 + 현재 주문력 × 주문 계수**. 예전 공격력 기반 이중 배율은 제거했습니다.
- 스킬 피해 유형과 계수는 구분합니다. 혼합 계수인 가이아 포스도 최종 피해 유형은 마법입니다.
- 모든 기본 공격은 **공격력 100%의 물리 피해**입니다. 발사체 외형이 전기/불꽃이어도 이 기본 공격 규칙은 같습니다.
- 대상당 총 피해를 연타 수로 나눕니다. 세븐 헤븐즈의 7발은 각각 총합의 1/7이며 대상 수로 나누지 않습니다. 표시량은 모든 타격이 같은 대상에 적중했을 때의 합계입니다.
- 물리는 방어력, 마법은 마법저항력을 사용해 `피해 × 100/(100+저항력)`으로 감소합니다. 기본 방어력/마법저항력은 0이며 수호자 시너지와 장비로 얻습니다. 현재 음수 저항력/관통은 없습니다.
- 저항력 → 받는 피해 감소 → 상황별 추가 피해 → 보호막 → 실제 체력 순서로 계산합니다. 정보창은 방어·상황별 추가 피해 적용 전의 값입니다.
- 피해 계산에 쓰는 공격력·주문력은 시전 시작에 확정합니다. 시전 후 장비/보너스가 바뀌어도 이미 발사한 기술의 피해는 바뀌지 않습니다.
- 최대 체력은 `(기본 체력 + 장비 체력) × 1.8^(성급−1) × (1+체력 비율 보너스)`입니다. 솔로 AI의 난이도/라운드 배율은 체력·공격력·주문력에 추가 적용합니다.
- 시너지 회복·보호막은 기존 최대 체력 계수와 회복량 증가를 사용합니다. 주문력은 아래 스킬의 주문 계수에 적용합니다.
- 디지몬 솔로/온라인은 동일한 기본 능력치, 계수, 사거리를 읽습니다. 오리지널 솔로는 이전 전투 규칙을 유지합니다.

## 사거리와 확인 방법

- 사거리는 홀수 행이 반 칸 밀린 전장의 육각 좌표로 계산합니다. 1칸은 인접한 여섯 칸을 포함하며, 이동 중에는 같은 좌표를 연속 보간합니다.
- 공격 범위를 벗어나면 접근하고, 범위 안에 들어온 뒤 기본 공격 또는 스킬 시전을 시작합니다. 각 스킬의 직선/원뿔/폭발 범위는 기본 공격 사거리와 별도입니다.
- 유닛 정보의 스킬 아이콘을 **우클릭**하면 현재 공격력·주문력·방어력·마법저항력, 기본 공격 사거리, 성급별 계수와 계산 피해를 봅니다. 닫기 버튼이나 Esc로 닫습니다.
- 솔로, 온라인 유닛 정보, 로비 도감에 같은 아이콘/상세창을 사용합니다. 온라인 전투 중 아군 체력바/몸체 윗부분을 클릭하면 해당 유닛 정보를 선택합니다.
- 전장 유닛은 장비+전장 시너지, 대기석은 장비만 반영합니다. 도감은 1성 기본값입니다. 전투 중 솔로는 시작 시 확정된 값을 표시합니다.
- 아이콘은 화염·발톱·광선·미사일·덩굴 등 기술 유형을 구분하는 코드 기반 문양입니다. 동일 계열 기술은 같은 형태를 공유하고 색상으로 구분합니다.

## 데이터와 검증

- `Assets/Resources/DigimonSkills.json`: 기본 체력/공격력/공속/사거리/마나와 모든 성급별 계수·피해 유형. `multiplier`는 제거했습니다.
- `Assets/Resources/DigimonBuilds.json`: 공격력 증가율, 정수 주문력, 방어력/마법저항력 등 장비·시너지 보너스. `skill` 보너스는 `abilityPower`로 교체했습니다.
- `python Tools/validate_code.py`: 일반 C# 컴파일, 기존 이동/스킬 검사와 서버↔C# 능력치·계수·거리·방어 계산 비교.
- `python -m unittest discover -s Server -v`: 같은 성급 AD/AP 비교, 혼합 계수, 시너지 합산, 실제 명중과 방어, 연타, 기본 공격 사거리 및 기존 서버 흐름.
- 실제 미리보기의 `--arena-smoke`, `python Tools/validate_online.py`: 실제 피해량·정보창 계산 일치, 스킬 아이콘/상세 화면, 장비/전투 흐름.
- 전체 경기 밸런스와 실제 두 PC 네트워크 환경은 반복 플레이로 추가 조정합니다.
