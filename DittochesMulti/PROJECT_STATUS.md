# 디토체스 진행 현황과 다음 작업

작성 기준: 2026-09-18. 진행 중이던 UI 패치를 마무리했습니다. 사용자 요청에 따라 현재 범위에서 검증·저장하고 다음 작업은 새 지시를 기다립니다.

최신 UI 패치: 디지몬 솔로 드래그가 같은 칸 안에서도 커서를 따라가고 목적지 강조는 별도로 유지합니다. 기존 이미지의 이동·스킬 변형을 부드럽게 보간하며 솔로·온라인 체력바의 겹침을 줄였습니다. 버튼 호버·지연 툴팁, 온라인 모집 카드와 레벨/XP/확률/구매 버튼 묶음, F/D/Space 단축키를 적용했습니다. 게임 규칙·새 3D 모델은 이번 패치 범위에 포함하지 않았습니다.

최신 모집·배치 패치: 솔로·온라인 상점 카드에서 공격/마법/혼합 유형과 사거리를 확인하고, 스킬 아이콘을 우클릭해 장비·시너지 없는 1성 스킬을 조회합니다. 준비 중 이동할 칸을 가리키면 교환 전후 시너지 인원과 활성/강화/약화/해제를 표시합니다. 교환으로 빠지는 유닛, 동일 종류 중복, 배치 인원 제한을 반영하며 실제 이동 전에는 구성이나 능력치를 바꾸지 않습니다.

최신 전투 패치: 기본 공격/스킬 피해 분리, 받은 피해·보호막 흡수·회복·보호막 생성 기록, 현재 체력·마나·보호막/기절/시전 상태 표시를 솔로·온라인에 연결했습니다. 온라인 완료 라운드는 준비 단계와 재접속 후에도 조회하며 솔로 기록은 유닛/장비 복사본을 보관합니다. 기존 육각 사거리·대상 선택·장비 미리보기도 유지합니다. 전체 규칙은 [COMBAT_STATS_AND_SKILLS.md](COMBAT_STATS_AND_SKILLS.md)에 있습니다.

장비 이름 추가 개편: 기본 재료를 디지조이드 3종/디지코어로, 완성품을 원작 고유 무장 10종으로 정리했습니다. 베렌헤나는 완성품으로 이동하고 V 브레이슬릿을 적용했습니다. 상세 UI에 용도·소재 설명을 표시하며 기존 저장 ID와 합성식은 유지합니다.

추가 완료: 문장 6종/전투 특성 5종, 30종 배정, 기본 장비 4종/완성 장비 10종, 캡슐 제외, 전투 효과·합성·상세 UI·저장 호환. 전체 설계는 [SYNERGIES_AND_EQUIPMENT.md](SYNERGIES_AND_EQUIPMENT.md)에 있습니다. 온라인 시너지에 이어 장비 보급·합성·장착·회수와 판매/별 합성 시 장비 보존까지 반영했습니다. 캡슐 증강은 후속 작업입니다.

현재 단계는 플레이 가능한 전투·UI 프로토타입입니다. 롤토체스처럼 자연스러운 3D 캐릭터와 전투 연출까지 완성된 상태는 아닙니다. 일반 플레이의 캐릭터는 기존 2D 이미지이며 전장 자체는 원근 카메라로 렌더링합니다.

## 유지할 작업 방향

- 디지몬 버전을 먼저 완성합니다. 오리지널 캐릭터 버전은 이후 캐릭터 교체 단계에서 진행합니다.
- 3D 모델 제작은 사용자가 집 PC에서 이어가기로 했으므로 현재 보류합니다.
- 추가 유료 생성 서비스를 사용하지 않습니다. 직접 제작한 아구몬 시험본은 별도로 보존했습니다.
- GitHub에는 코드 중심으로 올리고 이미지·모델 바이너리는 별도 에셋 보관소와 함께 관리합니다.

## 앞으로의 권장 작업 순서

1. **집 PC에서 최신 작업 기반 확보**
   - 현재 USB 프로젝트와 아트 보관소를 함께 옮깁니다.
   - Unity `6000.6.0f1`로 열어 C#·에셋·셰이더 임포트 오류를 확인하고 Windows 정식 빌드를 만듭니다.
   - GitHub의 `develop` 브랜치에 최신 작업을 업로드했습니다. 집 PC에서도 `develop`을 사용하고, 이전 상태인 `main`을 최신 작업으로 오인하지 않도록 합니다.

2. **아구몬 한 종을 3D 품질 기준으로 완성**
   - 얼굴·비율·재질·실루엣을 다듬고 관절과 스킨 가중치를 정리합니다.
   - 대기, 걷기, 방향 전환, 기본 공격, 피격, 스킬, 사망 동작을 연결합니다.
   - 발 미끄러짐, 관절 꺾임, 몸체 관통, 턱/입의 발사 위치를 실제 전장 크기에서 확인합니다.
   - 만족할 품질을 확보한 뒤 일반 플레이에 연결합니다. 현재 시험본을 그대로 전체 유닛의 완성 기준으로 삼지 않습니다.

3. **나머지 디지몬과 전설이 제작**
   - 이족·사족·비행·곤충·식물 등 체형별 관절 구조와 움직임을 만듭니다.
   - 유닛마다 알아볼 수 있는 외형, 크기, 자세와 공격 방식을 유지합니다.
   - 전설이의 이동·대기·전리품 회수·승리 동작도 같은 화면 품질에 맞춥니다.

4. **전투 모션·원작 기술·이펙트 통합**
   - 기본 공격과 기술의 준비 동작, 실제 명중, 회복 동작을 맞춥니다.
   - 기술 명칭과 대표 사용 장면을 유닛별로 확인하고, 발사 위치를 입·손·날개·무기에 연결합니다.
   - 걷기에서 공격으로 이어지는 전환, 기절·사망 중단, 이미 발사된 투사체 처리를 확인합니다.
   - 난전에서 체력바·스킬명·피해 숫자가 겹치거나 이펙트가 유닛을 가리지 않도록 조절합니다.

5. **그래픽·UI·조작 마무리 및 밸런스**
   - 정식 셰이더 기준 조명·그림자·재질과 배경 색 대비를 조정합니다.
   - 드래그 취소, 꽉 찬 대기석, 자동 합성, 장비 조합/장착, 관전 복귀, 저장·재개를 반복 확인합니다.
   - 화면 비율과 해상도에 따른 글자·툴팁·클릭 영역을 확인합니다.
   - HP, 공격력, 마나, 기술 피해/범위, 상점 확률, 경제와 난이도를 실제 플레이로 조정합니다.
   - 다수 유닛·동시 스킬 상황의 프레임과 메모리를 확인합니다.

6. **온라인 확장과 배포**
   - 먼저 현재 2인 대전을 두 PC에서 구매→배치→전투→결과까지 검증합니다.
   - 시너지와 장비 획득/장착은 서버에 적용했습니다. 크립·보상 선택 등 남은 기능을 이식하고 온라인 UI를 맞춥니다.
   - 이후 8인 리그, 친구 초대, 채팅, MMR 기준 매칭을 별도 설계·구현합니다.
   - 공용 서버, HTTPS, 정식 계정 인증, 운영·복구 구조를 준비합니다.
   - Android 빌드와 터치 조작은 실제 기기에서 별도 점검합니다.

7. **디지몬 버전 완성 후 오리지널 캐릭터 버전 진행**
   - 공통 전투/UI 코드를 유지하고 캐릭터·이름·기술 표현을 교체합니다.
   - 체형이 달라지는 캐릭터는 리깅, 애니메이션, 클릭 범위도 함께 조정합니다.

현재 우선순위는 집 PC에서 정식 실행 기반을 확인한 뒤, 아구몬 한 종의 3D 외형과 움직임을 먼저 완성하는 것입니다. 8인 매칭 같은 확장은 그 이후 순서입니다.
